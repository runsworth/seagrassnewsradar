METHODOLOGY

How the radar finds stories

1. Translingual search

GDELT is queried for seagrass, eelgrass, marine angiosperms and major seagrass taxa. It can match monitored news published in many languages through its machine-translated index.

2. Native-language searches

Google News RSS is also searched using local vocabulary such as pastos marinos, herbiers marins, Seegras, lamun, หญ้าทะเล, アマモ, 잘피 and 海草床, plus Latin species names.

3. Deduplication

The same story can be found by more than one route. URLs and normalised titles are used to merge duplicate discoveries.

4. No fictional content

The site starts empty. The first GitHub Action creates a real 30-day baseline. Baseline stories are not labelled “new today”.

Important: no global news index captures every outlet. This combines a broad translingual index with explicit native-language searches to reduce English-language and major-media bias, but coverage will still vary by place and publisher.
